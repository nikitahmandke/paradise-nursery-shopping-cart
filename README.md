# Paradise Nursery Shopping Application

Paradise Nursery is an online e-commerce platform designed for plant lovers to browse, discover, and purchase various houseplants. 

## Features
- **Landing Page**: Introduction to Paradise Nursery with smooth navigation to the store.
- **Product Listing**: Categorized plants with pricing, imagery, and instant add-to-cart capabilities.
- **Shopping Cart**: Real-time quantity adjustments, price calculations, and checkout preview powered by Redux Toolkit.

## Tech Stack
- React
- Redux Toolkit
- Vite / CSS3
